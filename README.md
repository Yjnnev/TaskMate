# TaskMate
An app to make managing tasks easier

## Installation & Setup

To get the app up and running on your Android device, follow these simple steps:

### 1. Download the App
Head over to the [Releases](https://github.com/Yjnnev/TaskMate/releases) page and download the latest `.apk` file (usually named `app-release.apk`) listed under **Assets**.

### 2. Enable Unknown Sources (If needed)
Because this app isn't being downloaded from the Google Play Store, Android requires you to allow installation from unknown sources:
* **Android 8.0 (Oreo) and newer:** When you open the downloaded APK, your phone will prompt you to grant permission to your browser or file manager to "Install unknown apps." Tap **Settings** in the prompt and toggle on **Allow from this source**.
* **Older Android versions:** Go to **Settings > Security** and check the box for **Unknown Sources**.

### 3. Install and Run
* Open your device's **Downloads** folder or file manager.
* Tap on the downloaded `.apk` file.
* Select **Install** when prompted.
* Once completed, tap **Open** to launch the application!
